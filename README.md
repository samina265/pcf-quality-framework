# pcf-quality-framework
BEACON: A data quality assessment framework for machine learning-based Product Carbon Footprint (PCF) prediction using the Carbon Catalogue dataset.

Project Structure

```

BEACON-PCF/
│
├── data/
│
├── notebooks/
│
├── src/
│
├── figures/
├── results/
├── scripts/
├── .gitignore
├── README.md
└── requirements.txt

```
Dataset
The Carbon Catalogue dataset is not included in this repository.
Please download it from the official source before running the notebooks.

Technologies

- Pandas
- NumPy

- Matplotlib
